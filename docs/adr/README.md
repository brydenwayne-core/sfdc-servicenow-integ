## ADR Quality Standard

Each ADR should include the following sections to ensure consistency and architectural rigor:

1. Context
2. Issue statement
3. Decision drivers
4. Decision
5. Alternatives considered
6. Consequences (positive and trade-offs)
7. Assumptions
8. Risks and mitigations
9. Measurable follow-up actions
10. Cross-links to architecture, process, runbook, and admin documents
